# Limitations

*Plain-language note: what this project cannot tell you, and where it is weak. Read it before quoting any number.*

1. **No database contains TbCu7 itself.** The TbCu7 numbers are a *proxy* built from ordered relatives (SmFe5, Sm2Fe17, Sm3Fe29, SmFe12). Real disordered TbCu7 carries extra mixing entropy (reported separately, about 11 meV/atom at SmFe9 and 1273 K) and some disorder enthalpy that no database captures. Treat the proxy as an estimate, not a measurement.
2. **Stoichiometry decides the crystal family.** Families come from composition, not from structure matching (no structure-matching library could be installed in the build environment). Cubic cells are excluded, and Zr and Hf are placed on the Sm site when that gives a standard ratio. A different structure that happens to share a ratio could be mislabeled. This mostly affects Al-, Ga- and Si-rich entries, which the ±0.10 composition window then keeps out of most comparisons.
3. **The verdict depends on the window.** The 50 meV/atom formability window is a convention. Results at 25 and 100 meV/atom are in `sensitivity.csv`. For MP, OQMD and Alexandria nearly every Sm-Fe value sits at 15 to 25 meV/atom, so the hit count says little. The discrimination test (`stats.json` → `discrimination`, Figure 2) is the more informative result.
4. **Literature evidence is uneven.** 30 observations are scored. Several rest on an abstract or only a title (column `evidence`), and some phase compositions are assumed (column `phase_comp_basis`, labelled "assumed"). The author reviewed these assumptions before release (2026-10-18); confirming each against the full text is listed in `NEXT_STEPS.md`.
5. **Many experiments contain extra elements.** Several Zr and V observations contain a few at% Co. The Singleton 1989 alloys sometimes contain B or C. These are scored against the ternary Sm-Fe-M system and flagged in `minor_additions`.
6. **One "not formed" case.** Specificity rests on a single observation: binary SmFe12 is not obtained by melt spinning (O10, with O12 as support). SmFe12 does form as epitaxial thin films, so "not formed by rapid solidification" is not the same as "cannot exist".
7. **Moments: two databases only.** MP and OQMD do not expose magnetic moments on their keyless interfaces. JARVIS gives one moment per cell, so the Sm contribution is assumed to be zero. Alexandria gives per-site moments, with Sm 4f electrons treated as core. The measured value is at room temperature and was scaled to 0 K with Kuz'min's formula (shape parameter 0.3 to 0.7). That is an assumption.
8. **Functional and corrections differ between databases.** MP uses GGA/GGA+U with its 2020 correction scheme. OQMD uses PBE(+U) with fitted chemical potentials. Alexandria uses PBE. JARVIS uses OptB88vdW. Energies are compared *within* each database, never across them.
9. **GNoME's public file lists only newly predicted compounds.** Known phases (Sm2Fe17, SmCo5, ...) are absent by design, so GNoME's "no data" is about scope, not quality.
10. **NOMAD was used through its search API for the inventory, and through Alexandria's OPTIMADE endpoint for energies.** NOMAD's own search index does not expose formation energies. The NOMAD-hosted MP and OQMD mirrors were not double counted.
11. **Snapshot in time.** The databases change. Values are as served on 2026-10-13 (see `data/raw/PROVENANCE.txt`). The OQMD queries needed retries because of timeouts, and all 13 systems eventually returned.
12. **Literature search was not exhaustive.** Candidates came from OpenAlex keyword searches (queries in `data/curated/literature_screen.md`) and two review articles' reference lists. Papers without an open abstract were included only when the title states the phase. Non-English full texts were not read.
